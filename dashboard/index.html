How a value is implied

Every protocol on this board records no token in the snapshot, so there is no price to copy — each value is implied from the snapshot's own figures. Start with a protocol's TVL. Multiply by its category multiple: the median market-cap-to-TVL ratio of protocols in the same category that already have a token, computed from this snapshot (categories with too few tokenized peers use the global median). Adjust for momentum (the last 7 days of TVL change, clamped so one wild week cannot dominate), maturity (longer-listed protocols have survived more market cycles) and breadth (protocols live on more chains reach more users). Nothing is scored by name: feed the formula a new snapshot and it ranks protocols that do not exist yet, which is the whole point of a radar. Protocols that already have a token are set aside, not ranked — they are counted below as the live set.

implied value = TVL × category multiple × momentum × maturity × breadth
